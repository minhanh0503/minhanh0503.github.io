My Journey 🚀

Full-Stack developer Intern

NGSC Vietnam | March 2025 - September 2025

  • What I did: API development, data optimization, frontend integration
  • Scale: 150M+ financial records
  • Impact: Faster queries, smaller storage footprint, smoother UX
  • What I learned: Optimization is a team sport; UX matters as much as algorithms
  • Tech I used: Java, Spring Boot, Oracle SQL, REST APIs, JavaScript, React, TypeScript, Git, Postman
  • During my internship, I worked across a microservices‑based system, building and optimizing REST APIs that handled over 150 million financial records. I improved query performance, reduced storage usage, and refactored services so data could be processed and retrieved more efficiently across the architecture. I also helped fix production issues in both the backend and the web app, and contributed to the frontend by integrating APIs and implementing new features based on team requirements. The biggest lesson I learned was that optimization isn’t just about algorithms, it’s about communication, consistency across microservices, and designing for real user experience. What seems “efficient” in one service can break another, so collaborating with the team and aligning decisions across the system became just as important as writing clean code.
